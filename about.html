About Coffee World

A user-centred coffee information website

This page explains the purpose of the project and the design goals behind the website.

Project Purpose

Coffee World was designed as a computing project artefact using HTML and CSS. Its purpose is to make coffee information easier to access and understand.

Design Goals

  • Clear and simple navigation
  • Accessible page structure
  • Responsive design for different devices
  • Comparison features to support decision-making
